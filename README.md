# AHHO Filter — versão do TCC (2024)

> **Repositório arquivado.** Esta é a versão original, apresentada no TCC. Uma nova versão, reescrita para rodar 100% no navegador com OpenCV.js, está em desenvolvimento.

Ferramenta web educacional para aprender processamento digital de imagens: você carrega uma imagem, escolhe um filtro (realce, suavização, cor, limiarização, segmentação), ajusta os parâmetros e compara o antes e o depois.

Trabalho de Conclusão de Curso *"Explorando o Processamento de Imagens com OpenCV: uma ferramenta interativa para facilitar o aprendizado e aplicações práticas na web"* — Bacharelado em Ciência da Computação, UENP, 2024.

## Tecnologias

- **Backend:** Python, Flask, OpenCV
- **Frontend:** HTML, CSS, Bootstrap, JavaScript

## Como rodar

```bash
cd TCC/meu-projeto
pip install flask opencv-python numpy
python app.py
```

Depois, abra `http://localhost:5000` no navegador.
